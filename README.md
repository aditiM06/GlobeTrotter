# 🌍 GlobeTrotter

**GlobeTrotter** is a personalized travel planning platform that helps users create, organize, and manage multi-city trips in one place.

## ✨ Features

- 🔐 User Signup & Login with JWT authentication
- 🏠 Personalized Dashboard
- ✈️ Create, edit, and delete trips
- 📍 Search and add cities to trips
- 🎯 Discover and add activities
- 🗓️ Build multi-city itineraries
- 💰 Track expenses and trip budgets
- 📊 View budget and cost breakdowns
- 📱 Responsive and user-friendly interface

## 🛠️ Tech Stack

**Frontend**
- React
- Tailwind CSS
- React Router
- Recharts

**Backend**
- Node.js
- Express.js
- JWT

**Database**
- MySQL

## 🏗️ Structure

```text
GlobeTrotter/
├── frontend/
└── backend/
````

## 🚀 Run Locally

### Backend

```bash
cd backend
npm install
npm run dev
```

Create a `.env` file with your MySQL and JWT configuration.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## 👤 Demo

Users can create their own account through the **Sign Up** page.

> No personal credentials, database passwords, or secret keys are included in this repository.

## 🎯 Vision

GlobeTrotter aims to make travel planning simple, personalized, and interactive by bringing destinations, itineraries, activities, and budgeting together in one platform.
